# Frontend · Clase S21

## Ejecutar localmente

1. Desde esta carpeta, instala dependencias con `npm install`.
2. Inicia el servidor de desarrollo con `npm start`.
3. Abre la dirección indicada por Vite, normalmente `http://localhost:5173`.

La página está vacía intencionalmente. React y React DOM están instalados, pero no hay componentes ni plantilla de interfaz.

## Trabajo por realizar

- Crear el componente principal de React y componentes reutilizables para encabezado y tarjetas.
- Mostrar el nombre del emprendimiento y tres productos o servicios con nombre, descripción y precio.
- Pasar la información de cada tarjeta mediante props.
- Usar state para agregar productos al pedido y vaciarlo.
- Cuando estén listas las rutas backend, consumir la API con solicitudes a `/api`.

Vite y el plugin de React ya están instalados. El proxy local reenvía `/api` al backend en `http://localhost:5001`.
